🛒 Blinkit Sales Data Analysis Using Python

📌 Project Overview

This project focuses on analyzing Blinkit's sales data to identify business trends, understand customer preferences, and evaluate outlet performance.

The analysis uses Python and its data analysis and visualization libraries to extract meaningful insights from the dataset and support data-driven business decisions.

🎯 Objectives

- Analyze overall sales performance.
- Understand the impact of item categories on sales.
- Identify customer preferences based on item characteristics.
- Evaluate outlet performance across different locations and sizes.
- Analyze the relationship between outlet establishment year and sales.
- Identify key business insights and trends.

🛠️ Technologies & Tools Used

- Python – Programming language
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization
- Jupyter Notebook – Development environment

📊 Analysis Performed

1. Data Cleaning and Preprocessing

- Checked for missing values.
- Identified and handled duplicate records.
- Standardized column names and data formats.
- Prepared the dataset for analysis.

2. Exploratory Data Analysis (EDA)

- Analyzed total sales.
- Examined item-wise sales performance.
- Compared sales across different item categories.
- Evaluated outlet-wise sales performance.
- Analyzed sales trends based on outlet establishment year.

3. Data Visualization

Created visualizations to understand:

- Sales by item type.
- Sales by outlet size.
- Sales by outlet location.
- Sales by fat content.
- Outlet establishment trends.
- Average sales and item visibility.

🔍 Key Performance Indicators (KPIs)

The following business metrics were considered:

- Average Customer Rating

🚀 How to Run This Project

1. Clone this repository:

git clone https://github.com/Divyashree200409/blinkit-sales-data-analysis.git

2. Navigate to the project directory:

cd blinkit-sales-data-analysis

3. Install the required libraries:

pip install pandas numpy matplotlib seaborn jupyter

4. Launch Jupyter Notebook:

jupyter notebook

5. Open "Blinkit_Data_Analysis.ipynb" and run the cells.
